# Фото автомобиля

Кладём сюда снимки, галерея на главной подхватывает их сама.

- Порядок — по имени файла: `car-1`, `car-2`, `car-3`…
- Форматы: `.jpg`, `.png`, `.webp`, `.avif`. Astro сам пережмёт в AVIF и WebP,
  подставит `width`/`height` и нарежет размеры под экраны.
- Подписи к первым трём заданы в `src/components/CarGallery.astro`, в объекте
  `captions`. Для незнакомого имени берётся общая подпись — четвёртое фото
  ничего не сломает.
- Исходники лучше класть большими (от 1600 px по длинной стороне): уменьшить Astro
  сможет, увеличить — нет.
