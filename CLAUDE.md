## 1. Что это за проект

`estoniatransfer.ee` — сайт услуги **трансфера к погранпереходам Эстонии с
Россией**: Таллинн — Койдула, Таллинн — Лухамаа, Таллинн — Нарва.

**Мы не делаем сайт с нуля на пустом домене: домен занят и работает.** Там стоит
WordPress, и по решению владельца (17.08) он **заменяется полностью** на
статический сайт — вариант «А» из двух обсуждавшихся. Что было на домене до
замены, зафиксировано в [docs/old-site-snapshot.md](docs/old-site-snapshot.md);
читать перед любыми правками, иначе легко потерять то, что уже в индексе.

- Язык сайта: **русский**, тексты и комментарии в коде тоже на русском.
- Конверсия: не форма, а переход в мессенджер или звонок (как на старом сайте).

### Отношение к проекту ridego.ee

Это **другой проект**, у него своя папка, свой ключ и свой репозиторий. Общего
кода нет и заводить не надо. Но опыт переносится: тот сайт статический, без
сборки, с посадочными страницами под маршруты — здесь разумно повторить подход,
а не изобретать заново. **Цены, телефоны и тексты из ridego сюда не копируем:**
это разные бизнесы с разными цифрами.

## 3. Стек и принципы

| | |
|---|---|
| Тип | статический сайт, **без сборки** — ни npm, ни бандлера, ни фреймворка |
| Код | чистые HTML + CSS + ES5-совместимый JS в IIFE (`"use strict"`) |
| Зависимости | **ноль**: ни внешних шрифтов, ни CDN |
| Просмотр локально | открыть `public/index.html`, либо `npx serve public` |
| Что уезжает на хостинг | ровно содержимое `public/` |

Правила, которые проверяем при каждой правке:

- **Контраст текста не меньше 4.5:1** (WCAG AA, это смотрит PageSpeed).
- Анимации появления включаются только при работающем JS; без JS контент виден.
- Есть блок `@media (prefers-reduced-motion: reduce)`.
- После правки `styles.css` или `script.js` увеличиваем `?v=` в ссылках: статика
  кешируется, иначе вернувшийся посетитель получит новый HTML со старым CSS.
- Ключи и приватные данные в репозиторий не коммитим (см. `.gitignore`).

## 5. Деплой

`git push` в `main` → GitHub Actions → `rsync -rlvz --delete public/ → htdocs/`.
Репозиторий: `github.com/kirillkotsergin/estoniatransfer.ee`.

⚠️ **Главная ловушка, и здесь она опаснее, чем кажется.** `--delete` означает:
хостинг становится точной копией `public/`. Пока в `public/` нет готового сайта,
**любой запуск деплоя снесёт работающий WordPress**. В проекте ridego на это уже
наступали: перезапуск старого прогона выложил заглушку и удалил живой сайт.

Поэтому здесь сделано так:

1. Workflow запускается **только вручную** (`workflow_dispatch`), пока сайт не
   готов. Переключить на `push` — после первого успешного выката.
2. Перед `rsync` идёт **проверка готовности**: если `public/index.html`
   отсутствует, пуст или в `public/` меньше пяти файлов — деплой падает, не
   дойдя до копирования.
3. После копирования — smoke-check: страница должна отдавать `200` и содержать
   ожидаемую строку, иначе прогон красный.
