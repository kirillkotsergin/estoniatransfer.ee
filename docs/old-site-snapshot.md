## Структура: одна страница

Это ключевой факт для замены. В карте сайта **один URL**, в REST API
**одна страница** (`Главная`) и **ноль записей**:

```
https://estoniatransfer.ee/        lastmod 2026-05-28
```

Значит, карта редиректов при замене почти не нужна: сохранить и не сломать
надо ровно один адрес — корень. Всё остальное будет новым, а не заменой.

Отдельно: `sitemap.rss` объявлен в `robots.txt`, но индекс карты ссылается
только на `page-sitemap.xml`. Мусорных URL вида `/sample-page/` в индексе нет.

## Выводы для нового сайта

1. **Терять нечего, кроме корня.** Одна страница, 131 слово — переносить
   контент почти не нужно, редиректы сводятся к сохранению `/`.
2. **H1 и структура** — первое, что нужно исправить: сейчас его нет.
3. **Незанятые направления.** Тарту, аэропорт, обратные маршруты, российская
   сторона, паром из Хельсинки на сайте не описаны ни словом — это готовые
   темы для отдельных страниц.
4. **Языки.** Сайт только русский, при том что домен `.ee` и аудитория в
   Эстонии частично эстоно- и англоязычная.
5. **Что подтвердить у владельца перед публикацией:** актуальность цен
   130/160/200 €, какой из двух телефонов основной, за что цена 200 €.
